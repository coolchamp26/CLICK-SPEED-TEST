# ⚡ Click Speed Test

A fast, responsive web application that measures how quickly a user can click within a given time period. The app calculates Clicks Per Second (CPS) and provides performance feedback such as Slow, Average, Fast, or Pro Clicker.

Built purely for fun, practice, and improving reaction speed.

## 🚀 Features

### ⏱️ Multiple Test Durations
- 1 second
- 5 seconds
- 10 seconds
- 30 seconds

### 🖱️ Real-Time Click Tracking
- Live click counter
- Countdown timer during the test

### 📊 Accurate CPS Calculation
- CPS = Total Clicks / Test Duration
- Rounded to 2 decimal places

### 🏆 Performance Rating System
- 🐢 **Slow** (0–4 CPS)
- 🙂 **Average** (4–6 CPS)
- ⚡ **Fast** (6–8 CPS)
- 🚀 **Pro Clicker** (8+ CPS)

### 🔁 Instant Retake
- Restart test anytime
- Switch duration after completion

### 💾 Best Score Tracking
- Highest CPS stored locally using `localStorage`

### 📱 Mobile-Friendly
- Fully responsive layout
- Optimized for touch devices

## 🧠 How It Works

1. Select a test duration
2. Click the **Start** button
3. Click as fast as possible until the timer ends
4. View your:
   - Total clicks
   - CPS score
   - Performance rating
5. Try again to beat your best score!
